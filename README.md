# Exam Edge

**Exam Edge** is a full-stack examination platform designed to enforce sequential exam progression based on successful completion. It enables structured, timed assessments with automatic result generation at the end of each exam sequence.

---

## 🚀 Features

- ✅ Sequential exam unlocking based on previous exam results
- ⏱️ Timed exams with countdown functionality
- 📊 Result generation and display after each exam
- 🔐 Authentication and user session management (if implemented)
